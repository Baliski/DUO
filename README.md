# DuoDrive

Site responsivo de uma locadora fictícia de veículos elétricos e a gasolina, criado como projeto da disciplina de Desenvolvimento Front-End para Web.

## Como abrir

Baixe ou descompacte a pasta e abra o arquivo `index.html` no navegador. O site funciona offline, pois o Bootstrap e a fonte estão na própria pasta.

## Tecnologias

- HTML5 semântico
- CSS3 (Flexbox, Grid, media queries e variáveis)
- JavaScript puro (DOM, eventos e localStorage)
- Bootstrap 5.3

## Estrutura

- `*.html`: as 11 páginas do site, todas na pasta raiz
- `css/`: `estilo.css` e o Bootstrap
- `js/`: scripts de cada página e o Bootstrap
- `img/`, `video/`, `audio/`, `fonts/`: mídias do site
- `doc/`: documentação do projeto em Word
